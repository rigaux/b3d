\subsection{Que calculent les expressions suivantes ? }

En imaginant que vous travailliez sur un fichier XML stockant un ensemble de
livres, -en ``devinant" la sémantique associée,- que cherchent à calculer
les expressions suivantes d'après vous.

\begin{enumerate} 
\item \url{preceding-sibling::chapter[position()=1] }
\correction{sélectionne le précédent chapter cible du noeud contextuel}
\item \url{/descendant::figure[position()=42] }
\correction{sélectionne le 42ème élément figure du document}
\item \url{/child::doc/child::chapter[position()=5]/child::section[position()=2] }
\correction{sélectionne la 2ème section du 5iÃ¨me élément chapter de l'élément
doc du document}
\item \url{child::para[attribute::type="warning"] }
\correction{sélectionne tous les enfants para du noeud contextuel qui ont un attribut type dont la valeur est warning}
\item \url{child::chapter[child::title='Introduction'] }
\correction{sélectionne l'enfant chapter du noeud contextuel qui a un ou plus enfant title avec un contenu textuel égal Ã  'Introduction'}
\item \url{child::chapter[child::title] }
\correction{sélectionne l'enfant chapter du noeud contextuel qui a un ou plus enfant title}
\item \url{child::*[self::chapter or self::appendix] }
\correction{sélectionne tous les enfants chapter et appendix du noeud contextuel}
\item \url{child::*[self::chapter or self::appendix][position()=last()] }
\correction{sélectionne le dernier enfant chapter ou appendix du noeud contextuel}
\end{enumerate}

Donnez les notations abrégées de ces expressions.

\subsection{Chercher à montrer que\ldots}
\noindent Mettez en {\oe}uvre un (ou plusieurs) test(s) permettant de tester si les
expressions suivantes sont équivalentes. 
Expliquer le fonctionnement de ces expressions.\\ \\
Première expression :
\url{child::para[attribute::type='warning'][position()=5]} 
\correction{sélectionne le 5ème enfant para du noeud contextuel qui a un
attribut type dont la valeur est warning. Donc (1) va chercher les para et (2)
sélectionne ceux de type warning, puis (3) ensuite parmi ceux-là prend le
5eme}\\ \\
Deuxième
expression : 
\url{child::para[position()=5][attribute::type="warning"]} \correction{sélectionne le 5ième enfant para du noeud contextuel si celui-là a
un attribut type de valeur warning. Donc (1) sélectionne les para, (2) sélectionne le 5ème
et (3) teste si ce 5eme a le type warning. }\\  \\
Troisième expression : 
\url{child::para[position()=5 and
attribute::type="warning"]} \correction{ (1) Sélectionne
les para et prend celui en 5eme position s'il a aussi le type warning.
Equivalent à 2 ici juste parce qu'on a fait le test le plus restrictif d'abord.}

et

\begin{enumerate}
  \item (Sur papier) Représenter l'arbre XML, vu par XPath, associé au fichier.
  \item (Sur machine) Ecrivez les requêtes XPath suivantes : 
\begin{enumerate}
\item Quelles sont les noms des différentes bases de données répertoriées ? 
\correction{/DatabaseInventory/DatabaseName/GlobalDatabaseName/text()}
\item Quelles sont les administrateurs des bases de données répertoriées ?
\correction{/DatabaseInventory/DatabaseName/Administrator }
\item Quel est le numéro de version du SGBD de la base de données de production
?
\correction{/DatabaseInventory/DatabaseName/DatabaseAttributes[@Type='Production']/@Version}
\item Quel est le premier administrateur de la dernière base de données ? 
\correction{/DatabaseInventory/DatabaseName[last()]/Administrator[1]}
\item Quel est le dernier administrateur de l'avant dernière base de données ? 
\correction{/DatabaseInventory/DatabaseName[last()-1]/Administrator[last()]}
\item Quels sont les SID Oracle utilisés ? 
\correction{//OracleSID}
\item Quels sont les SID Oracle des BDs administrées par quelqu'un ayant
l'extension 6008 ? 
\correction{/DatabaseInventory/DatabaseName[Administrator[@Extension='6008']]/OracleSID}
\item Quels sont les SID Oracle des BDs administrées par quelqu'un ayant
l'extension 6008 ou l'extension 6007?
\correction{/DatabaseInventory/DatabaseName[Administrator[@Extension='6008' or @Extension='6007']]/OracleSID}
\item Quels sont les administrateurs ayant une extension ? 
\correction{//Administrator[@Extension]}
\item Quels sont les emails des administrateurs ayant une extension ? 
\correction{//Administrator[@Extension]/@EmailAlias}
\item Quels sont les types d'utilisation des BDs Oracle de version 9i ? 
\correction{/DatabaseInventory/DatabaseName/DatabaseAttributes[@Version='9i']/@Type}
\end{enumerate}
\end{enumerate}
