\begin{itemize}

XPath se sont pas implantées dans l'évaluateur disponible à cette adresse
(\texttt{count} et \texttt{text()} par exemple).
\item Installer le logiciel BaseX (Système open source de gestion native de
bases de données XML) que vous pouvez télécharger sur
\url{http://www.inf.uni-konstanz.de/dbis/basex/} (prendre le .jar).
\item (Pas faisable en salle de TP mais faisable ``chez vous'' avec des droits d'administrateur sur votre machine) Installer le logiciel eXist (Système open source de gestion native de
bases de données XML) que vous pouvez télécharger sur
\url{http://www.exist-db.org/download.html}. Y créer une base de données de
schéma DB.dtd et contenant le seul fichier DB.xml puis interroger 
la collection via vos requêtes XPath.
Note : si vous désirez ``jouer'' avec eXist et XPath, vous pouvez chargez la
collection Samples (installée avec eXist).
\end{itemize}

\lstinputlisting{ED2_XPath/Codes/xhtml_et_mathml.xml}

\begin{enumerate}
\item \'Ecrivez des requêtes XPath permettant de :
\begin{enumerate}
\item Récupérer tous les commentaires.
\correction{//comment()}
\item Récupérer tous les éléments du namespace XHTML. Que remarquez-vous ? 
\correction{//*[namespace-uri()='http://www.w3.org/1999/xhtml']. Les éléments math ne sont pas dans le namespace xhtml}
\item  Récupérer tous les éléments du namespace MathML. Que remarquez-vous ?
\correction{//*[namespace-uri()='http://www.w3.org/1998/Math/MathML']}
\item Récupérer tous les commentaires situés dans un élément \texttt{body}.
\correction{//*[local-name()='body']/comment()}
\end{enumerate}
\item Créer un autre document de même contenu dans lequel vous déclarez explicitement le namespace XHTML (avec préfixe).
\item Vérifier à l'aide de la requête que vous avez définie en (b) que les mêmes éléments se trouvent bien dans le namespace XHTML.
\item Retirez le prefixe de la balide \texttt{<b></b>} et vérifier à l'aide de la requête que vous avez définie en (b) que l'élément \texttt{b} ne se trouve plus dans le namespace XHTML.
\item Ouvrez chacun des documents avec Firefox. Cela confirmera encore ce que vous venez de remarquer.
\end{enumerate}

\subsection{Equivalence de notation}
Les notations suivantes sont équivalentes : V ou F ? Justifiez.\\
\texttt{/descendant-or-self::auteur[1] }\\
\texttt{//auteur[1] }

\correction{
Le chemin de localisation \texttt{//auteur[1]} n'est pas équivalent à
\texttt{/descendant::auteur[1]}.\\
\texttt{/descendant-or-self::auteur[1]} sélectionne le premier élément descendant
auteur.\\ Pour comprendre la seconde expression, le plus simple est de développer le
raccourcis de notation.\\
 \texttt{//auteur[1]}  (cad
\texttt{/descendant-or-self::node()/child::auteur[position()=1]} cad
\texttt{/descendant-or-self/auteur[1]}) sélectionne tous les éléments auteur
descendants (donc hors racine) qui sont les premiers éléments auteur de leurs parents.\\
