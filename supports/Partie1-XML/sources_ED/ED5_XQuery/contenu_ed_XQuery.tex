
\subsection{Les livres}
Cet exercice est très inspiré du cours XQuery du W3 Schools.

\subsubsection{Matériel}
\noindent Avant toute chose, Récupérez le fichier \texttt{books.xml} sur la page Pli@d.\\

Cet ED consiste en la rédaction de requêtes XQuery permettant d'interroger ce fichier. Pour tester vos requêtes XQuery, deux solutions s'offrent à vous :
\begin{itemize}
\item (Pas faisable en salle de TP) Installer le logiciel eXist (Système open source de gestion native de
bases de données XML) que vous pouvez télécharger sur
\url{http://www.exist-db.org/download.html}. Y créer une base de données 
contenant le fichier \texttt{books.xml} et l'interroger (attention à bien choisir votre contexte d'évaluation et à bien préfixer vos requêtes par \texttt{doc('books.xml')}.
\item Installer le logiciel BaseX (Système open source de gestion native de
bases de données XML) que vous pouvez télécharger sur
\url{http://www.inf.uni-konstanz.de/dbis/basex/} (prendre le .jar), 
créer une base de données à partir du fichier \texttt{books.xml} et l'interrogez  dans la fenêtre intitulée XQuery.
\end{itemize}

  \correction{\includegraphics{ED5_XQuery/PourPoly/prix_inf30-1.png}\\

  \correction{\includegraphics{ED5_XQuery/PourPoly/titre_prix_inf30-1.png}\\

  \correction{\\ for \$x in doc("books.xml")/bookstore/book\\
where \$x/price>30\\
order by \$x/title\\
