\subsection{Votre Curriculum Vitae}
\begin{enumerate}
\item \'Ecrivez votre Curriculum Vitae en format XHTML. Validez votre document à l'aide du validateur de la W3C (\url{http://validator.w3.org/}).

\section{Seconde partie : XSLT}

Dans l'exercice qui suit, vous aller produire un fichier XHTML à partir d'un fichier XML et d'une feuille de style XSL. Vous allez définir une structure de présentation des informations du fichiers XML permettant une lecture humaine aisée. Tout au long de l'exercice, vous modifierez la feuille de style de façon à la rendre de plus en plus complexe, pour un rendu XHTML de plus en plus sophistiqué.
\subsection{Un interpréteur XSLT}
Nous vous rappelons ici que le fichier XHTML est produit à partir d'un fichier XML et d'une feuille de style XSL par un outils (un programme) appelé \textit{interpréteur XSLT}. Au moins quatre solutions s'offrent à vous pour accéder à un interpréteur XSLT :
\begin{enumerate}[$\bullet$]
\item(\`A privilégier en TP) L'interpréteur XSLT explicite du logiciel XMLCooktop.\\ Le logiciel XMLCookTop, installé sur vos environnements Windows, intègre un interpréteur XSLT. La prise en main de CookTop se fait facilement.
\item Le module \texttt{TransforMiiX} de Mozilla. \\Pour l'utiliser,
\begin{enumerate}
\item Référencez le fichier XSL associé (\url{<?xml-stylesheet type=``text/xsl''  href=``mon_fichier_XSL.xsl'' ?>}) dans le fichier XML à transformer (voir cours) ;
\item Ouvrez le fichier XML avec Mozilla ;
\item L'interpréteur XSLT de Mozilla a fonctionné ``automatiquement'' et vous propose le rendu du code XML produit.
\end{enumerate}
L'inconvénient de cette méthode est qu'on ne peut pas voir le document XHTML généré mais seulement son rendu sous forme de page web. Attention, \texttt{TransforMiiX}  n'intègre pas toutes les fonctionnalités du language XSLT. 
\item L'interpréteur XSLT explicite \texttt{Saxon} écrit en java. \\Utiliser le fichier \emph{saxon9he.jar} téléchargeable à l'adresse \url{http://saxon.sourceforge.net/} (version HE, pour java) ou tout simplement dans la liste des fichiers de l'ED (sur la page de votre professeur) . Copier ce fichier dans un répertoire de travail (par exemple intitulé \emph{ED\_XSLT}) dans lequel vous mettrez également tous les fichiers que vous créerez au cours de l'ED. \\ Pour utiliser l'interpréteur de Saxon, utilisez la commande suivante : \\
{\small \texttt{java -jar saxon9he.jar -t -s:mon\_premier\_fichier\_input.xml -xsl:mon\_second\_fichier\_input.xsl
\linebreak
-o:mon\_fichier\_output.extension}} (sur une seule ligne).\\
Pour plus d'information, {\small \texttt{java -jar saxon9he.jar -help}}.
\item L'interpréteur XSLT explicite \texttt{Xalan} écrit en java. \\Pour l'utiliser,
\begin{enumerate} 
\item Téléchargez Xalan sur la page
\url{http://www.apache.org/dyn/closer.cgi/xml/xalan-j} ;
\item Récupérez le fichier nommé \textit{transform} sur
Plei@d et
instanciez le chemin d'accès des fichiers .jar en l'adaptant à votre configuration,
\item Exécutez le fichier \textit{transform}.
\end{enumerate}

\end{enumerate}

\medskip

Note : L'attribut \verb?method? de l'\'el\'ement \verb?output? ne peut prendre la valeur \verb?xhtml? que pour êre traité par un processeur XSLT 2.0. Certains navigateurs int\'egrant un processeur XSLT ne traitent pas XSLT 2.0. Dans ce cas, vous pouvez soit retirer l'attribut \verb?method? et sa valeur (soit tout l'\'el\'ement \verb?output? si celui-ci n'apporte pas d'autre information d'int\'er\^et, sachant que l'encodage par d\'efaut est UTF-8), soit indiquer la valeur à \verb?xml? ou \verb?html?.

\subsection{XSLT\ldots par la pratique\ldots}

\begin{enumerate}
\item Récupérez le fichier XML \texttt{bibliotheque.xml} sur Plei@d et
complétez-le à l'aide de trois livres de votre choix (sans modifier les autres
livres) traitant de XML ou de Bases de données.
\item Créez une feuille de style qui
permet de générer un fichier XHTML dont le rendu sous forme d'une
page web a la forme suivante (NB: la page
web doit contenir un sommaire listant les livres puis les livres détaillés).
\includegraphics{ED3_XSLT/PourPoly/final_ss_ancres.png}
\item Utilisez balise \url{<xsl:if>}\footnote{Voir
\url{http://www.w3.org/TR/xslt#section-Conditional-Processing-with-xsl:if} }
afin de
\begin{enumerate}
\item n'afficher ``Description :'' que si un abstract existe
\correction{<xsl:if test="abstract"> Description : <xsl:value-of select="abstract"/>
</xsl:if>
}
\item afficher les noms de auteurs sous la forme de autheur1\underline{,}
auteur2 \underline{et} auteur3\underline{.}
\correction{\lstinputlisting{ED3_XSLT/PourPoly/xslt_bout_if.xsl}}
\end{enumerate}
\item La balise \url{<xsl:sort>}\footnote{Voir
\url{http://www.w3.org/TR/xslt#sorting}} permet de trier des élements. Faites
en sorte que les livres soient affichés par ordre descendant de la date de
parution. 
\correction{\lstinputlisting{ED3_XSLT/PourPoly/xslt_bout_sort.xsl}}
\item \`A l'aide de la balise \url{<When>}\footnote{Voir
\url{http://xmlfr.org/w3c/TR/xslt/#element-when}}, afficher ``Résumé : ''
quand le livre est en français et ``Abstract : '' quand le livre est en anglais.
\correction{\lstinputlisting{ED3_XSLT/PourPoly/xslt_bout_when.xsl}}
\item Utilisez la fonction \texttt{generate-id()} de XPath afin de créer des
ancres permettant de lier les titres des livres décrits à ceux du sommaire.\\
Indication : La réponse se trouve sur le site du W3C\ldots A vous de la
trouver et la mettre en {\oe}uvre. Chercher \texttt{generate-id} sur la doc de
XSLT à \url{http://www.w3.org/TR/xslt}.
\item De façon à tester la robustesse de votre feuille de style, prenez le
fichier \texttt{library.xml} de votre voisin et appliquez-lui votre feuille de
style.
\end{enumerate}
